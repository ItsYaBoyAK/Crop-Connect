# Crop-Connect
An AI Model made in 2024 which won us the AI innovator accelerator

To Use:
just enter the image path in the untitled jupyter notebook instead of OIP.jpg and have the image stored in the directory
This was a preliminary model made in a short time and with a thought of expanding to android studio in future. The model predicts whether the crop is healthy or has got some disease in it based on prior samples. Made using tensorflow.
